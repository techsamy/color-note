# 05 — API Specification (v1)

Base URL: `https://api.<domain>/api/v1` · JSON only · Auth: `Authorization: Bearer <sanctum-token>`
The source-of-truth OpenAPI file will be generated by Scribe; this document is the design contract.

## 1. Conventions
- Headers sent by app: `Accept: application/json`, `X-Device-Id: <uuid>`, `X-App-Version: 1.0.0+12`.
- Timestamps: UTC epoch **milliseconds** for note fields; ISO-8601 for account/meta fields.
- Success envelope: `{ "data": ..., "meta": {...} }`.
- Error envelope:
```json
{ "error": { "code": "VALIDATION_FAILED", "message": "Human readable", "fields": { "email": ["..."] } } }
```
| HTTP | code | When |
|---|---|---|
| 400 | BAD_REQUEST | malformed |
| 401 | UNAUTHENTICATED | missing/expired token |
| 403 | FORBIDDEN | not owner |
| 404 | NOT_FOUND | |
| 409 | CONFLICT | (per-record, inside sync response — not whole request) |
| 422 | VALIDATION_FAILED | |
| 426 | APP_UPGRADE_REQUIRED | app version below `min_supported` |
| 429 | RATE_LIMITED | `Retry-After` header |
| 5xx | SERVER_ERROR | client retries with exponential backoff |

- Rate limits: auth endpoints 10/min/IP; sync 60/min/user.

## 4. Sync
### `POST /sync/push`
```json
{
  "changes": [
    {
      "entity": "note",
      "id": "0192f0c4-...",
      "base_version": 4,
      "data": { "type": 1, "title": "Groceries", "body": "[...]", "color": 3,
                "is_pinned": false, "is_archived": false, "is_locked": false,
                "crypto_meta": null, "reminder_at": null, "reminder_rule": null,
                "reminder_all_day": false, "status_bar_pinned": false,
                "calendar_date": null, "created_at": 1730800000000,
                "updated_at": 1730800500000, "deleted_at": null }
    },
    { "entity": "color_label", "id": "3", "base_version": 7, "data": { "label": "Shopping" } }
  ]
}
```
Max 200 changes per request; body ≤ 2 MB.

Response `200`:
```json
{
  "data": {
    "results": [
      { "id": "0192f0c4-...", "status": "applied", "version": 5 },
      { "id": "3", "status": "conflict", "server": { "version": 8, "data": { "label": "Shop" } } }
    ]
  }
}
```
`status` ∈ `applied` | `conflict` | `rejected` (with `error`, e.g. `READ_ONLY` for viewers of a shared note).
The client sends one flat note object; the server splits shared fields (`notes`) and personal fields (`note_members`: colour, pin, archive, reminder).

### `GET /sync/pull?cursor=41&limit=500`
```json
{
  "data": { "changes": [ { "entity": "note", "id": "...", "version": 5, "data": { ... },
                            "owner": { "uuid": "...", "name": "A" }, "my_permission": 0 } ] },
  "meta": { "next_cursor": 57, "has_more": false, "server_time": 1730800600000 }
}
```
- `cursor=0` = full initial sync (**used when signing in on a new device**).
- Deleted notes come with `deleted_at` set (tombstone). A revoked share arrives as a tombstone too.
- **Delete forever** = push with `deleted_at` + `purged: true`: the server wipes title/body/crypto_meta and keeps the
  tombstone; devices that pull `purged: true` delete the note locally. A purged note can't be edited again (conflict).
- Token name = `device_uuid`; one live token per device (signing in again replaces it).
- Implementation: `api/app/Services/SyncService.php` — tests in `api/tests/Feature/Api/V1/SyncTest.php`.

## 4b. Master-password keys
| Method | Path | Notes |
|---|---|---|
| GET | `/me/keys` | `{key_material, key_version}` or 404 if none set yet. `key_material` = the app's `KeyMaterial` JSON (keyId, kdf, wrappedDek, wrapNonce, recovery*) |
| PUT | `/me/keys` | Set/replace (password change) `{key_material, expected_key_version}` — 409 if another device changed it first |

The server only stores opaque blobs; it can't decrypt anything.

## 5. Config
`GET /config` (no auth) →
```json
{ "data": { "min_supported_version": "1.0.0", "latest_version": "1.0.3", "features": { "calendar": true } } }
```

## 6. Versioning rules
- Additive changes (new optional fields, new endpoints, new `entity` types) are allowed in v1.
- Clients must ignore unknown fields and unknown entity types.
- Removing/renaming a field or changing meaning → `/api/v2`.
