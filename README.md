# HueNote (working name)

Offline-first, colour-coded notes & checklists for Android — inspired by ColorNote, rebuilt with a modern UI, real privacy and room to grow. Free, no ads, no tracking.

| Part | Stack | Folder |
|---|---|---|
| Mobile app | Flutter (Android first, iOS-ready) · Riverpod · Drift/SQLite | `app/` *(to be scaffolded)* |
| Backend | Laravel · MySQL · Redis · Sanctum | `api/` *(to be scaffolded)* |
